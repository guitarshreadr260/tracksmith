TRACKSMITH INSTRUMENT - BUILD 29

Extract the entire ZIP and open TracksmithInstrument.exe. Keep sfizz.dll, Assets and Samples beside the executable.

CREATIVE FX: Click CREATIVE FX near the top. Warp adds moving pitch-like delay; Reverse Slices plays half-second pieces backwards after a delay; Drive adds saturation; Stereo Width adjusts existing stereo difference. Reset FX returns all controls to zero. At zero the creative effects are bypassed. Changes last for the current session. Reverse Slices is a live effect, not full backwards playback of each individual sample.

Select Meta Upright Piano in Piano & Keys. The compact 16-bit library uses five roots and four velocity layers. Output boost, EQ and compression remain under EQ / Compression. Start with speakers or headphones at a low level. This is a Windows standalone prototype, not VST3.

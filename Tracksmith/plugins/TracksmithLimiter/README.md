# Tracksmith Limiter development

Stereo-linked sample-peak limiter with instantaneous gain reduction, adjustable release, input drive and ceiling. Zero latency. It is not a true-peak limiter and does not use lookahead or oversampling. The submitted circuit page could not be inspected because it returned a verification screen. This implementation is an independent digital design.

Previews and automated tests only; no new DAW installer or portable package has been prepared. Listening and broader transient/automation measurements remain.

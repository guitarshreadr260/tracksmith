# Tracksmith Plate

Original plate-style eight-line feedback-delay network with input diffusion, pre-delay, damping, input low-cut and stereo width. No modulation. Decay is a nominal low-frequency tail setting; damping changes the perceived decay. Allocations happen during prepare, not processing; reset clears preallocated memory. The wet path produces a diffuse tail; use 100% mix on an aux send.

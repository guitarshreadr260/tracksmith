# Tracksmith Fet development

Input-driven fast compressor with a fixed internal threshold, four normal ratios, custom Slam mode, stereo-linked feedback gain control, and parallel mix. Original behavioral prototype; it does not model transistor/FET/transformer nonlinearities or claim hardware equivalence. Timing settings are control-loop time constants; measured response varies with ratio and signal. No oversampling. References: https://www.gyraf.dk/gy_pd/1176/1176.htm and https://media.uaudio.com/assetlibrary/2/-/2-1176_manual.pdf . No Gyraf schematic, layout or project implementation was copied.

Previews and automated tests only; no new DAW installer or portable package has been prepared. Listening and broader transient/automation measurements remain.

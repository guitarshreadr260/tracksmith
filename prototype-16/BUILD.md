# Prototype 16 source checkpoint

Download this repository, then run `python prototype-16/restore-source.py`. Extract the verified ZIP. It contains the current C++ engine, React/TypeScript UI, artwork, native Groove/NAM integration, stock-plugin sources, third-party source dependencies, tests, MIDI grooves and implementation guides.

Large runtime payloads are **not uploaded**: drum samples/packs, NAM model, pretrained neural weights and bundled Node executable. `external-assets.json` records exact relative paths, sizes and SHA256 hashes. Restore those paths from the complete local Prototype 16 source/portable package before running native instruments or reproducing the packaged validation. The full local source and portable ZIP hashes are in `LOCAL-PACKAGE-SHA256.json`; those ZIPs are not GitHub downloads.

The source ZIP excludes dependencies/caches generated by npm, compiled UI, native build outputs and WebView2 SDK binaries. From `Tracksmith/ui`, install the locked dependencies with npm and run `npm run build` (or use `Build-UI.ps1`). Configure CMake 3.22+ with Visual Studio 2022/2026 C++ tools; JUCE 8.0.10 is fetched by CMake. Provide WebView2 SDK headers under `vendor/Microsoft.Web.WebView2` or the SDK location supported by JUCE. Set `TRACKSMITH_ASIO_INCLUDE_DIR` to your ASIO SDK headers, or use `-DTRACKSMITH_ENABLE_ASIO=OFF`. Enable `TRACKSMITH_STUDIO_TESTS=ON` for the four native regression targets. Build Release. Keep Stock Plugins and Native Instruments beside Tracksmith.exe.

The included build/package/check scripts are the executed workspace helpers, supplied for reference. Their workspace-relative paths are not a portable one-command build system. The CMake project and UI package scripts are the authoritative build inputs.

`prototype16-test-results.json` records executed automated checks. UI interaction checks use simulated engine state. Native engine and packaged executable checks ran separately. Real ASIO/interface, latency, disk-load and listening checks remain pending. Elastic Audio is researched, not implemented.

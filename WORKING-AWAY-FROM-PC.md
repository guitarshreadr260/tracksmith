# Working away from the home PC

Sign in to GitHub as guitarshreadr260 and open your private tracksmith repository. Bookmark its README. Read PROJECT-STATUS.md for the latest handoff and the guides for specific behavior.

Use GitHub Issues to record bugs or ideas. For a bug, include the build, what you clicked, what you expected and what happened. Return to the development chat with the issue link so it can be addressed. This repository is a saved reference, not remote control of the home PC; publishing updates here is a separate step from making local changes.

Windows builds can be downloaded from the repository or Releases to a compatible Windows computer. The DAW and VST3 do not run on a phone. Do not install software on a work computer unless your workplace permits it.

Your private repository is visible only to accounts you explicitly grant access. Future chat access to the repository may require a separate GitHub connection. GitHub does not automatically contain or synchronize the local conversation history.
